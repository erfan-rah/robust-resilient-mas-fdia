# Robust &amp; Resilient Multi-Agent Systems Against FDIAs

For my Robust Control course project, I simulated a resilient and robust distributed control protocol for
multi-agent systems subject to sensor and actuator attacks. To this end, a distributed H∞ control protocol
was designed by solving a linear matrix inequality (LMI), yielding a controller capable of maintaining
performance under adversarial conditions. This repository contains the simulations file and presentation slides of this project.
